# Translator 0.5.0-preview

Автоматический перевод текста внутри приложения после паузы 700 мс.
Работает при вводе, вставке, завершении диктовки и смене языков.
Режим можно отключить; настройка сохраняется. Озвучка — по кнопке.
Первая загрузка моделей требует интернета (по умолчанию Wi-Fi).

Установите APK поверх предыдущей версии Translator.
Это debug preview. Сборка и Android Lint проверяются перед публикацией;
на физическом телефоне новая версия пока не проверена.
