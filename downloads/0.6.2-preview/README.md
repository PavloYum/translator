# Translator 0.6.2-preview

Исправлено зависание прослушивания при смене языка с пустым полем.
Нажатие перевода/озвучки без текста больше не отменяет микрофон.
Распознавание больше не запрашивает только офлайн-движок по умолчанию;
предпочтение офлайн доступно в настройках. Сервис Android может использовать сеть.
Добавлены сообщения о недоступном речевом пакете, языке, микрофоне и сети.
Ожидание распознавания ограничено 45 секундами, перевода/моделей — 90 секундами.
Различаются значки разговора (микрофон) и одной фразы (облако текста).

Для немецкой речи выберите слева Deutsch, справа Русский.
Подключите интернет, оставьте предпочтение офлайн-распознавания выключенным.
Модель перевода de и пакет распознавания немецкой речи — разные компоненты.

MQTT на предыдущей версии подтвердил модели de/en/ru и тестовый перевод RU→DE;
микрофон дистанционно не проверялся. Новая сборка требует проверки на телефоне.
Debug preview, установка поверх предыдущей версии.
