# Translator 0.6.1-preview

Крупные кнопки внутри карточек заменены рядами контурных значков.
Долгое нажатие показывает название действия; доступны подписи для TalkBack.
Размер области нажатия 48 dp. Активный разговор выделяется зелёным.
В блок перевода добавлен значок «Поделиться» через системное меню Android.
Переключатели автоматического перевода и озвучки сохранены.

Установка поверх 0.6.0, прежняя подпись. Debug preview.
Сборка и Android Lint проверяются перед публикацией. На телефоне интерфейс пока не проверен.
