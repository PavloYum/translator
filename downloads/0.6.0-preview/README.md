# Translator 0.6.0-preview

- «Начать разговор»: последовательное распознавание фраз без повторных нажатий.
- «Озвучивать перевод автоматически»: сохранённый выбор; работает также для ввода текста.
- Микрофон приостанавливается во время перевода и озвучки.
- Остановка кнопкой, при сворачивании и блокировке экрана. Во время разговора экран остаётся включённым.
- Разрешение микрофона и согласие на системное распознавание при первом запуске.
- Интернет для распознавания зависит от установленного сервиса Android.
- Аудиовыход выбирает Android: подключите наушники и проверьте громкость мультимедиа.

Установить поверх 0.5.0. Debug preview, физический телефон и Bluetooth-маршрутизация пока не проверены.

Проверка: включить автоозвучку, начать разговор, произнести две фразы по очереди,
дожидаясь окончания озвучки. Проверить остановку, тишину, сворачивание, отказ
в разрешении микрофона, отсутствие голоса и потерю сети.
