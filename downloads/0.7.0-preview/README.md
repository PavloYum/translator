# Translator 0.7.0-preview

Вкладка «Журнал»: локальная история успешно завершённых переводов.
Сохраняются исходная фраза, перевод, языки, время и идентификатор диалога.
Сохранение включено по умолчанию, отключается галочкой во вкладке журнала.
Новый диалог — значок облака текста; старые записи остаются в истории.
У записей есть копирование и удаление всего соответствующего диалога с подтверждением.
Удаление всей истории — корзина вверху. История загружается по 50 записей.

База находится в закрытом каталоге приложения, в MQTT не передаётся.
Аудио разговора не записывается. Удаление приложения удаляет локальную историю.
Автоматические переводы во время набора также сохраняются при успешном завершении.
Прежние диалоги до установки этой версии восстановить нельзя.

Сборка, Android Lint и тесты SQLite (повторное открытие, Unicode, уникальность
запроса, страницы и удаление диалога) проверены перед публикацией.
На физическом телефоне новый интерфейс пока не проверен. Установка поверх 0.6.2.
