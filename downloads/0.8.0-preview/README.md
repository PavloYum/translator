# Translator 0.8.0-preview

- Исправлено выполнение PRAGMA secure_delete в Android SQLite; результат записи проверяется.
- Журнал обновляется после сохранения, сохраняется также результат при одинаковых языках.
- Офлайн-разговор использует системный on-device распознаватель (Android 12+), если он доступен.
- Загруженные модели перевода используются без предварительного запроса загрузки.
- Вкладка «Языки»: установленные модели ML Kit, голоса без требования сети, сведения о речевых пакетах.
- Речевые пакеты проверяются через API Android 13+. Если провайдер не отвечает, показано «неизвестно», а не «не установлено».
- Загрузка моделей перевода RU/DE/EN; запрос установки речевого пакета выбранного языка.
- Звуки нажатий приложения отключены. Сигналы системного распознавателя могут остаться: общего поддерживаемого переключателя в используемом API нет. Глобальная громкость телефона не меняется.

Список моделей перевода не доказывает наличие моделей распознавания речи.
На старом Android/без on-device сервиса офлайн-разговор недоступен.
Кнопка «Одна фраза» продолжает использовать внешний системный диалог с предпочтением офлайн.

Сборка, Android Lint и тесты SQLite проверяются перед публикацией. Работа на физическом телефоне требует проверки.
Установка поверх 0.7.0, существующая база журнала сохраняется.
