# 0.1.0-experiment

Android 8+. Запись до 60 секунд, один приватный WAV, удаление записи.
Системный TTS RU/DE/EN: выбор доступного офлайн-голоса, скорость и высота тона.
Перевод, облачное распознавание и фоновые сессии ещё не реализованы.

Проверено: assembleDebug, lintDebug (0 ошибок, 5 предупреждений), APK signature,
6 Python-тестов. На физическом телефоне ещё не проверено.

[Прямая загрузка APK](https://github.com/PavloYum/translator/releases/download/v0.1.0-experiment/translator-lab-0.1.0-debug.apk)

Это debug-подпись, не окончательный release-ключ; будущая смена ключа может
потребовать переустановки. Файл SHA256SUMS позволяет проверить загрузку.
