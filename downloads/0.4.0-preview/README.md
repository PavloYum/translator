# Translator 0.4.0-preview

[Скачать APK](https://github.com/PavloYum/translator/releases/download/v0.4.0-preview/translator-0.4.0-preview.apk)

## Изменения
- Фоновая MQTT-связь с Pi в отдельном foreground service. Переход в чат больше
  не отключает канал и не отменяет самопроверку.
- Постоянное уведомление с кнопкой «Отключить». Отдельные команды start/stop,
  восстановление соединения при доступной сети. Никакого микрофона в сервисе.
- Три вкладки: «Перевод», «Связь с Pi», «Настройки». Карточки ввода/результата,
  понятные статусы, копирование перевода, локальная самопроверка, значок приложения.
- Отчёт и время последней проверки на экране; TTS для диагностики проверяется
  отдельным движком, целевой язык фиксирован DE. Звук при проверке не воспроизводится.
- Прежние настройки MQTT и голоса сохраняются при обновлении поверх 0.3.

## После установки
1. Разрешите уведомления. Вкладка «Связь с Pi» должна показать MQTT подключён.
2. Если выключено: «Настройки» → «Сохранить и включить связь». Пароль повторно
   вводить не нужно, если он уже сохранён.
3. Нажмите «Запустить самопроверку». Для полного теста нужны загруженные RU/DE.
4. Перейдите в чат и попросите проверить: связь должна остаться в уведомлении.
5. На Xiaomi при отключении сервисов системой проверьте разрешение фоновой
   работы/экономию батареи в настройках приложения.

После принудительной остановки или перезагрузки откройте приложение заново.
Foreground service не гарантирует постоянную сеть при Doze, ограничениях HyperOS,
отключении интернета или остановке пользователем. Фоновое слушание речи и фоновая
озвучка не добавлены: этот сервис только для диагностики.

## Проверка
Проверено: assembleDebug и lintDebug (0 ошибок, 9 предупреждений), совпадение
подписи с 0.3, 6 Python-тестов и 8 проверок CommandGuard.
Фоновое подключение на физическом телефоне и внешний вид на Redmi требуют
проверки после установки. Не выдавать успешную сборку за аппаратный тест.
