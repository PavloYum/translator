# Translator 0.3.0-preview

MQTT-самопроверка по запросу с Pi: модели, готовность TTS, тест RU→DE и задержка.
Без передачи личного текста, аудио, удалённого включения микрофона или динамика.

1. Установить APK поверх 0.2.
2. Найти внизу «Удалённая самопроверка MQTT».
3. Ввести отдельный логин и пароль, полученные приватно. Нажать «Сохранить и включить MQTT».
4. Оставить приложение открытым. При сворачивании MQTT отключается.
5. Чтобы проверить перевод, предварительно перевести RU→DE с интернетом для загрузки моделей.

[APK](https://github.com/PavloYum/translator/releases/download/v0.3.0-preview/translator-0.3.0-preview.apk)

Подробности протокола: [mqtt/README.md](../../mqtt/README.md).
Проверены сборка, lint, подпись, защита команд, обмен с брокером и внешняя WSS-аутентификация.
Работа на физическом телефоне ещё не подтверждена. Это preview с прежней debug-подписью.
