# Translator 0.8.1-preview

Выбор языка оформлен просторным списком с мягким выделением выбранной строки.
Нажатие названия выбирает язык; значок справа показывает состояние пакета перевода
и позволяет скачать его. Галочка загрузки появляется после проверки ML Kit.
Списки доступны на главном экране и во вкладке «Языки».
Доступны прежние три языка: русский, немецкий, английский.
Загруженный пакет перевода не означает наличие речевого пакета; сведения о речи
и голосах остаются отдельными во вкладке «Языки».

Установка поверх 0.8.0. Сборка и Android Lint проверяются перед публикацией.
Внешний вид на физическом телефоне пока не проверен.

Нижняя навигация оформлена вкладками: общая панель, выделенное название и полоска активной вкладки.
