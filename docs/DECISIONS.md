# Открытые решения

1. **Решено пользователем 24.11.2026: личное использование.**
   Первый релиз без подписок, платежей, тарифных квот, email OTP и сервера лицензий.
   Офлайн-функции не блокируются через 72 часа. Приватный доступ через Tailscale;
   отдельный отзывной токен приложения, без публичной регистрации.
   Ограничения расходов облачных API и защита шлюза сохраняются.
2. Модель наушников и версия Android/HyperOS на тестовом Redmi.
3. Разрешена ли передача речи облачным провайдерам и какой предел расходов?
   До выбора и согласования бюджетов платные API не подключать.
4. Нужно ли добавить украинский к RU/DE/EN? В PDF его нет; не считать прошлую
   просьбу об украинском языке сайта автоматически требованием к этому приложению.
5. Политика истории: предложение — локальная, сервер только по согласию.
6. Название/package ID и будущий GitHub visibility. Локальное рабочее имя Translator;
   package ID и публикация пока не утверждены. Приложение не копирует бренд/активы AICOOL.
7. Для личной версии срок офлайн-лицензии отсутствует; история и экспорт доступны без подписки.
8. Отдельный домен для шлюза и число одновременных пользователей.

Следующее действие разработки: измерительный аудиопрототип на реальном телефоне.

## Уточнение пользователя — 24.11.2026

Личное использование — первый этап, а не окончательная граница проекта.
Если пилот окажется удачным, пользователь планирует продавать приложение.
Подписки, лицензирование, платежи, управление устройствами, тарифные квоты
и коммерческая админка сохраняются в плане следующего этапа.
Провайдер платежей, цены, дата запуска и критерии коммерческого успеха не выбраны.

Архитектурное решение: отделить идентификацию пользователя, права доступа
(EntitlementPolicy), учёт потребления (UsageMeter) и оплату (BillingProvider).
Личный режим предоставляет функции без подписки; коммерческий подключает
лицензии и тарифы через те же интерфейсы. Это предложение к реализации, не
уже написанные модули. В пилоте сохранять user/session identifiers и измерение
расходов; не собирать разговоры ради будущего биллинга.

## Озвучка с настройками

По просьбе пользователя: системный TTS с выбором голоса, высоты тона и скорости,
предпрослушиванием и сохранением настроек для каждого языка, по образцу Massage Time.
Требования: [настройки озвучки](VOICE.md).

## 25.11.2026 — промежуточная версия 0.2
Пока платный провайдер не выбран, реализован on-device текстовый перевод ML Kit
и системный голосовой ввод через RecognizerIntent с предупреждением о возможной
обработке речи провайдером. Это не замена запланированному облачному исследованию
и не завершение полного этапа 2: нет foreground microphone service, непрерывного
режима, auth/server и стабильной release-подписи. Коммерческие планы сохраняются.
