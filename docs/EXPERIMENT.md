# Этап 1: аудиолаборатория (24.11.2026)

Статус: исходники, debug APK и локальные тесты готовы; этап целиком не завершён.
Облачный провайдер и бюджет ещё не выбраны. STT/MT, API-шлюз и интеграция
телефон → облако не реализованы. Никаких платных запросов не выполняется.

## Создано
- `android/`: отдельное экспериментальное Android-приложение на Java и системных
  виджетах; это измерительный стенд, не окончательный Kotlin/Compose интерфейс.
- RU/DE/EN, список голосов движка без требования сети, скорость и высота 0.5–2.0,
  сохранение по языку, предпрослушивание и остановка. Диапазоны экспериментальные.
- AudioRecord: PCM16 mono 16000 Hz, максимум 60 секунд; остановка при уходе
  приложения в фон. Один `sample.wav` в приватном каталоге, перезаписывается
  следующей записью; есть кнопка удаления, Android backup отключён.
- `experiment/audio.py`: ограничение размера, формата и длительности, проверка
  усечённого WAV, RMS dBFS, пик, доля перегруженных сэмплов, признак тишины.
  Это технические уровни цифрового сигнала, не калиброванные акустические дБ SPL.
- `experiment/summary.py`: p50/p95 методом nearest-rank, число измерений и ошибок;
  отсутствующие значения не заменяются нулями. Не оценивает стоимость без тарифов.
- `tests/`: отрицательные сценарии WAV, тишина/перегрузка, статистика задержек.

## Проверка на Pi
```sh
cd /home/pavel/translator
python3 -m unittest discover -s tests -v
python3 -m experiment /path/to/sample.wav
python3 -m experiment.summary /path/to/measurements.jsonl
```
Формат одной строки измерений (значения ниже только пример формата):
```json
{"success":true,"stt_ms":800,"translation_ms":300,"tts_start_ms":150,"total_ms":1250}
```
Общее время измерять отдельно от конца речи до первого звука, не выдавать сумму
серверных этапов за задержку пользователя. Не смешивать провайдеры и условия
в одном файле. Текст, ключи и аудио в журнал измерений не включать.

## Сборка Android
Общая среда на Pi: `/home/pavel/android-build`. Используются JDK 17,
Gradle 9.0.0 из wrapper проекта, AGP 8.13.0, Android SDK platform 35.
```sh
/home/pavel/android-build/bin/build /home/pavel/translator/android
adb install -r /home/pavel/translator/android/app/build/outputs/apk/debug/app-debug.apk
adb exec-out run-as com.veluvara.translatorlab cat files/sample.wav > sample.wav
```
Среда существовала в старом каталоге AndroidServerBot; ранее её ошибочно
посчитали отсутствующей. Теперь есть единая команда и общий кэш SDK/Gradle.
Не публиковать этот debug APK как готовый релиз. Package ID стенда временный.
Системный TTS другого приложения может иметь собственные сетевые настройки;
стенд выбирает голоса с `isNetworkConnectionRequired=false`, но офлайн-работу
надо подтвердить авиарежимом на конкретном устройстве.

## Приёмка на телефоне
1. Отказ разрешения микрофона, повторное разрешение, конкурирующее приложение.
2. Запись речи, тишины, громкого звука; 60-секундный предел, Stop, уход в фон.
3. Извлечь WAV через adb; проверить Python-командой, удалить образец.
4. RU/DE/EN, крайние настройки, перезапуск, отсутствие голоса, авиарежим.
5. Проверить Bluetooth, входящий звонок; аудиофокус пока не реализован,
   поэтому стенд не предназначен для повседневного фонового использования.
6. После подключения выбранного провайдера: ≥100 согласованных записей,
   измерения качества имён/чисел, p50/p95, стоимость, 30 минут нагрева/батареи.

Документация API: https://developer.android.com/reference/android/media/AudioRecord
и https://developer.android.com/reference/android/speech/tts/TextToSpeech.
