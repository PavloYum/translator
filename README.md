# Translator

Отдельный проект Android-переводчика с серверным шлюзом на Raspberry Pi 5.
Дата создания: 23 ноября 2026. Исходное ТЗ хранится локально и не входит в публичный репозиторий.

**Стадия: первый этап — аудиолаборатория. Исходники Android и локальные Python-тесты созданы; debug APK собран и прошёл Android Lint; облачный перевод не подключён.**
Ничего не развёрнуто на Pi, платные API не подключены, существующие сервисы не изменены.

Исходный объём: Android 8+, RU/DE/EN, синхронный перевод, ассистент,
встречи, офлайн-пакеты и поиск совместимых наушников. Предложение по первому
релизу уже исходного ТЗ; остальные функции не отменены, а выделены в следующие этапы.
Исходный PDF не публикуется. Репозиторий содержит код, документацию и версии APK.

## Решение пользователя — 24.11.2026

Приложение для личного использования. Без подписок, платежей и сервера лицензий.
Первый этап: RU/DE/EN, микрофон телефона, перевод текста и озвучка, приватный
шлюз через Tailscale. Облачные API могут оплачиваться отдельно: провайдер и
бюджет пока не выбраны. Наушники, встречи и офлайн остаются последующими этапами.

## Дальнейшее развитие

По уточнению пользователя от 24.11.2026 коммерческая версия остаётся целью
при успешном личном пилоте. Подписки и лицензии отложены, не отменены.
Архитектура должна позволять добавить оплату и тарифы без переписывания перевода.

## Озвучка с настройками

По просьбе пользователя: системный TTS с выбором голоса, высоты тона и скорости,
предпрослушиванием и сохранением настроек для каждого языка, по образцу Massage Time.
Требования: [настройки озвучки](docs/VOICE.md).
